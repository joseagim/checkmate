# Use of artificial intelligence

Statement of how AI is used in this project. It is kept up to date during development and feeds the corresponding section of the thesis.

**Tool:** Claude (Anthropic), in a Claude project with several chats, one per work area.

## Criteria by area

| Area | Who writes the code | Role of the AI |
|---|---|---|
| Frontend | The AI generates and the author reviews, tests and integrates | Generation of components, styles and interface logic |
| Backend | The author designs the architecture and the AI supports | Review, explanation, examples and help with errors |
| Custom engine (C++) | The author, entirely | Only comments on code already written and help locating bugs. No engine code is generated |
| Infrastructure (Docker, deployment) | Shared | Configuration and explanation |
| Planning and documentation | Shared | Roadmap organization, drafting of documentation |

## Working rules

- The author writes the custom engine code. It is the part with the most academic weight in the project.
- Everything generated by the AI is read, understood and tested before it is incorporated.
- Architecture decisions are made by the author; the AI provides alternatives and arguments.
